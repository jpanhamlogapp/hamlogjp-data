1はじめに・対応環境

HamLogJP は、アマチュア無線とフリラー（デジタル簡易無線・CB・特小・LCR ほか）の交信記録を、1つのアプリで管理できる日本語のログアプリです。iPhone・iPad・Mac でネイティブに動作します。

  • アカウント登録は不要です。すぐに使い始められます。
  • 交信ログは端末内に保存され、外部に送信されません。iCloud 同期をオンにすると、ご自身の iPhone・iPad・Mac 間でログを共有できます（Apple ID の iCloud を利用）。
  • 無料版で交信ログ 200 件まで、基本機能をお試しいただけます。ADIF 入出力や QSL 管理などはプレミアム版の機能です（第13章）。
画面の文言は端末の言語設定に追従します（日本語／英語）。公園名なども、日本語表示のときは日本語で表示されます。

2画面の構成

本アプリは端末に合わせて2つのレイアウトで動作します。

Mac・iPad は3ペイン

左に機能メニュー、中央に交信ログの一覧、右に入力欄が並びます。過去の交信を見ながら、そのまま次のログを入力できます。

iPhone は片手で速記

相手コール欄を大きく取り、バンドやモードはタップ（チップ）で選びます。左上のメニューから各機能に移動します。

3交信を記録する

「ログ入力」画面で1件ずつ記録します。基本の流れは ①サービスを選ぶ → ②相手コール／バンド・モード → ③RSTと相手情報 → ④「保存して次へ」 です。

サービスの切り替え

画面上部の「サービス」で アマチュア無線 と フリラー を切り替えます。切り替えると、入力欄がそれぞれに最適化されます（アマチュアはバンド／モード、フリラーは無線種別／チャンネル）。

バンドとモード

アマチュアではバンド（MHz）とモードをタップで選びます。モードには音声（SSB/CW/FM/AM）や FT8 等に加えて、デジタル音声モード（DV・D-STAR・C4FM・DMR）を標準で用意しています。

使うモードは「設定 → 表示するモード」で追加・削除できます（全48種から選択）。デジタル音声モード（DV/D-STAR/C4FM/DMR）はアップデート後、自動で入力チップに表示されます。

RST と相手情報

RST（送信＝相手へ／受信＝自分が受けた）を入力します。相手のお名前・QTH（住所）を記録でき、QTH 欄は市区町村名・都道府県・かな・ローマ字・コードのいずれでも検索できます。

保存

「保存して次へ」で1件を記録し、次の交信に備えて入力欄がリセットされます（自局の運用設定は保持されます）。

4フリラー（無線種別）

サービスを「フリラー」にすると、無線種別とチャンネルを選べます。

無線種別内容チャンネル
DCRデジタル簡易無線（351MHz）1〜82ch から選択
CB市民ラジオ（27MHz）1〜8ch から選択
特小特定小電力（422MHz）L1〜L11 / b1〜b9
LCRデジタル小電力コミュニティ1〜18ch から選択

Zello / エアインカムライトは固定チャンネルを持たないため、チャンネル欄が「チャンネル / ルーム名」の自由入力に自動で切り替わります。使ったルーム名をそのまま記録できます。

5入力を先回り

  • 過去の交信を自動表示：相手コールを入れると、その局との過去の交信が表示され、初回か何回目かも分かります。
  • 重複の警告：同じバンド・モードで既に交信済みの場合に知らせます（コンテストや移動運用で便利）。
  • JCC/JCG 内蔵：全国の市郡区 1,700 件超を内蔵。漢字・かな・ローマ字・コードで検索できます。
  • エリア自動補完：JA1ABC/2 のようなコールから運用エリアを判定して補います。

6POTA / SOTA

移動運用（POTA＝Parks on the Air、SOTA＝Summits on the Air）に対応しています。

  • 相手局の運用公園（ハント／P2P）や自局の運用公園を記録できます。
  • POTA 公園コードを内蔵。番号や名前で検索して選べ、日本国内の公園は日本語名で表示されます。データは定期的に自動更新されます。
  • 「POTA/SOTA スポット」画面で近隣の情報を確認できます。
公園コードは、コード番号を入力するとその番号から候補を出して選べます（直接入力＋候補選択）。

7コンテスト提出ログ（JARL電子ログ）

「データ」画面の「コンテスト提出ログ書き出し（JARL形式）」から、JARL 電子ログ形式（VERSION=R2.1）のサマリーシート＋ログシートを作成できます。主要8大会に対応しています。

大会ナンバー時刻
ALL JA コンテストRST＋都府県・地域ナンバー＋電力記号JST
6m AND DOWNRST＋地域(or市郡区)＋電力記号JST
フィールドデーRST＋地域(or市郡区)＋電力記号JST
全市全郡（ACAG）RST＋市郡区ナンバー＋電力記号JST
ALL ASIAN DXRST＋年齢（または01）UTC
QSOパーティRST＋オペレータ名JST
JARL World Wide RTTYRST＋年齢（または01）UTC
ウェルカムパーティRST＋初開局年下2桁＋局種JST

使い方：大会と参加部門（局種コード）、対象期間を選び、提出者情報（氏名・住所・E-mail など）を入力すると、テキスト（.txt）で書き出せます。大会ごとに部門コード・ナンバー様式・時刻（JST/UTC）へ自動で合わせます。

  1. 交信時に、相手からの受信ナンバー・自局の送信ナンバー（RSTを除く部分）を記録しておきます。
  2. 「データ」→「コンテスト提出ログ書き出し（JARL形式）」を開きます。
  3. 大会・部門・期間・提出者情報を入力し、「テキストで書き出し」または「共有」で保存します。
  4. JARL のログ提出ページからアップロード、またはメールで提出します。
部門コードは各大会の規約に基づいています。年度改定で変わる場合があるため、提出前に最新規約もご確認ください。

8データ入出力（ADIF / CSV）プレミアム

  • ADIF 書き出し／読み込み：他ソフトとの交換や過去ログの移行に。
  • Turbo HAMLOG CSV 取り込み：HAMLOG の「CSV形式で出力」ファイルに対応。文字コードは UTF-8 / Shift_JIS の両対応。
  • AirDrop 等で共有：iPhone で書き出して Mac へ直接受け渡し（その逆も可）。
  • 読み込み時は「コールサイン＋分単位の日時」が一致する交信を重複としてスキップするので、同じファイルを二度読んでも増えません。

9QSL 管理

交信ごとに QSL の扱い（ビューロー経由・ダイレクト・電子QSLのみ・不要）を設定でき、発送／受領の状況を管理できます。紙カードの発送対象を一覧で確認できます。

10統計・グラフ

月別・バンド別・モード別に交信を振り返れます。年間の交信数やアクティブなバンドがひと目で分かります。

11Es現況・宇宙天気・WiRES-X

  • 6m Es リアルタイム プレミアム：PSK Reporter の実データから、いま日本と開けている方向を地図で表示します。
  • 宇宙天気・太陽フレア：コンディションの参考情報を確認できます。
  • 近くの WiRES-X ノード：現在地周辺のノードを地図で表示します。

12設定

  • 自局情報：コールサイン・運用地・JCC/JCG などを登録。入力時に自動で使われます。
  • 表示するモード：入力チップに出すモードを選択（DV/D-STAR/C4FM/DMR も選択可）。
  • 単位：距離を km / mile で切り替え。
  • iCloud 保管：ご自身の端末間でログを同期。
  • 高コントラスト表示：見やすい配色に切り替え。
  • サブスクリプション管理：プレミアムの購入・復元・管理。
