HamLogJP プライバシーポリシー

本ポリシーは、アマチュア無線・ライセンスフリー無線用ログアプリ「HamLogJP」(以下「本アプリ」)における利用者情報の取り扱いを定めるものです。

1. 収集する情報

開発者は、利用者の個人情報を収集しません。交信ログ、リグ情報、設定などのデータは、お使いの端末内に保存されます。設定で iCloud 同期をオンにした場合は、利用者ご本人の iCloud(Apple のサービス)にも保存され、同じ Apple ID の端末間で同期されます。開発者がこれらのデータを取得・閲覧することはありません。利用者がご自身のメールアプリで開発者へメールを送った場合(お問い合わせ、特小レピーターMAP の掲載申請など)は、その内容を受け取ります(第5項)。

2. 位置情報について

本アプリは、運用地(現在地のグリッドロケーター・JCC/JCG)を自動入力する機能のために、利用者の許可を得たうえで端末の位置情報を利用します。位置情報は端末内での処理にのみ使用され、外部へ送信・保存されることはありません。位置情報の利用は、端末の設定からいつでも無効にできます。

3. 写真・画像について

「QSLカードを読み取る」機能では、利用者が写真ライブラリやファイルから選んだ画像だけを読み込み、文字の読み取りを端末内(Apple の Vision)で行います。この「QSLカードを読み取る」機能では、画像と読み取った文字を保存せず、外部へ送信しません。写真ライブラリ全体へのアクセスは求めません。

「D-STAR QSO Party 2026 の提出支援」では、次のデータを扱います。交信ログの情報、Party 用の補足(提出者のコールサイン・氏名・備考、使用機材、交信ごとの機器名などの補足)、利用者が選んだ主催者の公式 Excel ファイル、利用者が提出用に選んだ画像(JPEG・PNG)、本アプリが作成した提出用ファイル(Excel・ZIP)です。

  • 保存:選んだ画像と公式 Excel ファイル、Party 用の補足、作成した提出用ファイルは、お使いの端末内の本アプリの領域に保存します。これらは iCloud 同期の対象ではありません(第1項の交信ログ等の iCloud 同期とは別です)。補足から画像を外しても、取り込んだ画像のファイルは端末内に残ります。作成した提出用ファイルは、利用者の操作で、利用者が選んだフォルダへ保存したり、ほかのアプリへ共有したりできます。
  • 画像のメタデータ:本アプリは、選んだ画像をそのまま使い、画像に含まれる EXIF などのメタデータ(撮影日時・機種・GPS の位置情報など)を自動で削除しません。画像を提出すると、画像に含まれる情報も提出先に渡る場合があります。含めたくない情報がある場合は、画像を選ぶ前に利用者ご自身で確認・削除してください。
  • 送信:この機能は外部サーバーと通信しません。本アプリが大会の主催者へ送信したり、提出のメールを自動で送信したりすることはありません。共有先のアプリ(メールなど)へファイルを渡すこと、そのアプリから送信することは、いずれも利用者の操作です。渡したファイルは、共有先のアプリやサービスの規約に従って取り扱われます。

4. 通信について

本アプリは、次の目的で外部サーバーと通信します。

(1) 情報の取得のみ(利用者の個人情報・交信ログは送信しません)

  • JCC/JCG・POTA公園・WIRES-X ノードのデータ更新(開発者が GitHub Pages で配信するファイル)
  • 宇宙天気情報の取得(米国海洋大気庁 NOAA の公開データ)
  • 電離層 TEC マップ(米国海洋大気庁 NOAA の宇宙天気予報センターが公開する GloTEC のデータ)。画面を開いたときと利用者が更新を選んだときだけ取得し、端末内に保存します。取得の際、位置情報・交信ログ・自局のコールサインは送信しません。地図の色分けや目安は本アプリが独自に作成したもので、NOAA の公式情報ではありません。
  • 6m Es リアルタイム(PSK Reporter の公開データ)
  • POTA / SOTA のスポット情報(POTA・SOTA の公開データ)
  • SOTA の山岳一覧(SOTA が公開するサミット一覧ファイル)。利用者が山岳検索で取得・更新を選んだときだけ取得し、端末内に保存します。取得の際、交信ログ・自局のコールサイン・位置情報は送信しません。
  • DX Cluster のスポット情報(HamQTH の DX Cluster サービス)。DX Cluster 情報を取得する際、本アプリに保存された交信ログ、交信済み(Worked)の判定データ、QSL 管理の履歴を HamQTH へ送信しません。交信済みかどうかの判定は端末内で行います。

(2) 利用者が登録・操作したときだけ行う外部サービスとの連携

  • QRZ.com ログブック:利用者が登録した API キーを使い、利用者がアップロードを指示した交信のデータ(コールサイン・日時・周波数・モード・RST 等)を、利用者ご本人の QRZ.com ログブックへ送信します。
  • eQSL.cc:利用者が登録したユーザー名・パスワードを使い、利用者が送信を指示した交信のデータを、利用者ご本人の eQSL.cc アカウントへ送信します。また、利用者が「eQSL確認を取得」を選んだときだけ、登録したユーザー名・パスワードを使って、利用者ご本人の eQSL.cc アカウントから確認済み(CFM)のカードの情報を取得し、端末内の交信記録と照合して、eQSL の受信・確認の状態に反映します。
  • LoTW(ARRL Logbook of the World):利用者が登録したユーザー名・パスワードを使い、利用者の操作で、LoTW で確認(QSL)された交信の情報を取得します。LoTW への交信の送信は ARRL の署名ソフト TQSL で利用者が行い、本アプリは送信しません。

これらの通信は自動では行いません。送信したデータは各サービスの利用規約・プライバシーポリシーに従って取り扱われます。API キー・ユーザー名・パスワードは端末のキーチェーンにのみ保存し、iCloud には同期せず、開発者が取得することはありません。

5. 特小レピーターMAP の掲載申請・情報提供・訂正削除について

特小レピーターMAP への掲載申請、情報提供、掲載内容の訂正・削除の依頼は、メールで受け付けます。

  • メールアプリを開くのは利用者の操作です。アプリの「掲載の申請・情報提供」「この局の情報の訂正・削除を依頼する」を押すと、利用者の端末のメールアプリに、宛先と記入欄の入った下書きが開きます。
  • 本アプリがメールを自動で送信することはありません。下書きの内容を確認・編集し、利用者がメールアプリで送信したときだけ開発者に届きます。送信せずに閉じた場合、何も送られません。下書きに位置情報や交信ログが自動で入ることはありません。
  • 送信された情報の利用目的:お送りいただいたメールの内容(お名前・呼出名称・メールアドレス・レピーターの情報など)は、掲載の確認、掲載内容の訂正・削除への対応、およびそのための連絡にだけ利用し、第三者に提供しません。
  • 地図には、設置者が掲載に同意した項目だけを、設置者が選んだ位置の細かさで掲載します。メールアドレスや個人の連絡先を掲載することはありません。訂正・削除のご依頼には、次の掲載データの更新(アプリのアップデートを含みます)で対応します。

6. 音声入力・端末内 AI 機能について

音声でのログ入力では、利用者の許可を得てマイクを使い、Apple の音声認識で文字にします。対応する端末では端末内だけで処理します(非対応の端末では Apple の音声認識サービスで処理されることがあり、その取り扱いは Apple のプライバシーポリシーに従います)。AI 運用アドバイスなどは Apple Intelligence を利用して端末内で処理します。音声や入力内容を開発者へ送信することはありません。

7. アプリ内課金について

プレミアム版の購入は Apple の App Store を通じて処理されます。開発者が利用者の氏名・住所・クレジットカード情報等を取得することはありません。課金情報の取り扱いは Apple のプライバシーポリシーに従います。

8. 第三者への提供

開発者は利用者の情報を収集しないため、第三者に提供することもありません。広告表示や解析ツール(トラッキング)も使用していません。第4項(2)の連携は、利用者ご本人の指示により、利用者ご本人のアカウントへ送信するものです。

9. お問い合わせ

本ポリシーに関するお問い合わせは、App Store のサポートページに記載の連絡先までお願いいたします。

10. 改定

本ポリシーは、機能追加等に伴い改定されることがあります。重要な変更がある場合は、本ページにて告知します。
